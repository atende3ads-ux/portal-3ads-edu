# Assets do protótipo

Esta pasta guarda as imagens referenciadas pelas telas em `outputs/`.
Os arquivos binários ainda **não** foram versionados no repositório.

## Arquivos esperados

| Arquivo | Uso | Onde aparece |
|---|---|---|
| `logo-3ads-edu-blue.png` | Logotipo oficial, versão azul (tema claro) | `admin.html`, `trainer.html`, `index.html` |
| `logo-3ads-edu-white.png` | Logotipo oficial, versão branca (tema escuro) | `admin.html`, `trainer.html`, `index.html` |

| `profile-rafael.png` | Foto de perfil demonstrativa (Professor) | `enhancements.js` |

## Regras de identidade

Conforme `docs/06-design-system-e-ux.md`:

- usar exclusivamente o logotipo oficial 3ADS EDU;
- preservar proporção e área de respiro;
- versão azul no tema claro, branca no tema escuro;
- não sobrepor controles ao logotipo.

Enquanto os arquivos não forem adicionados, o navegador exibe o texto
alternativo (`alt="3ADS EDU"`) no lugar da imagem — o protótipo continua
navegável.
