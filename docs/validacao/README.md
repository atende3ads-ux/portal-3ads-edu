# Registros de validação

Uma sessão por arquivo, nomeado `perfil-data.md` — por exemplo, `admin-2026-09-22.md`.

O roteiro, o formato do registro e os critérios de classificação estão em
[`../16-roteiro-de-validacao.md`](../16-roteiro-de-validacao.md).

Ao final das seis sessões, consolidar em `resumo.md`.
